1. Using HTTP Get/Post -> Use the MyPages/Index.cshtml page
2. Using Querystrings -> Use the Mypages/QueryStringDemo.cshtml page. Received data is sent to DisplayInfo.cshtml page using query parameter.
3. Using Querystring for Multiple info -> Use the Mypages/QueryStringMultiple.cshtml page. Received data is sent to DisplayMultiple.cshtml page using query parameters.
4. Using JavaScript -> Use MyPages/UsingJavaScript.cshtml to receive user input, process it in the JavaScript function ShowInfo() and send the data to DisplayMultiple.cshtml page.
5. Using Request Form -> Use UsingRequestForm.chtml to receive input, process it on onPost() and send it back to the front end using ViewData[].
